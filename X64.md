# saramOS x64-qemu Execution Guide (virt-manager)

This guide provides instructions for building and running saramOS on an x86_64 architecture using `virt-manager`.

## 1. Prerequisites
Ensure the following packages are installed on your Linux system:
```bash
sudo apt update
sudo apt install virt-manager qemu-system-x86 nasm build-essential grub-pc-bin xorriso
```

## 2. Building the ISO
Execute the following command in the project root to build the `saramOS.iso` image:
```bash
make CONFIG=x64-qemu
```
This will produce `saramOS.iso` in the root directory.

## 3. Launching in virt-manager

1. **Create New Virtual Machine**:
   - Open `virt-manager` and click **"Create a new virtual machine"**.
   - Select **"Local install media (ISO image or CDROM)"**.
2. **Select Media**:
   - Click **"Browse..."** and locate the generated `saramOS.iso`.
   - For OS type, select **"Generic default"**.
3. **Hardware Allocation**:
   - Memory: **512 MiB** (or more).
   - CPU: **1**.
4. **Final Step & Customization**:
   - Name the VM `saramOS-x64`.
   - **Crucial**: Check the box **"Customize configuration before install"** and click **"Finish"**.
5. **Add Serial Console (Required)**:
   - In the settings window, check if there is a **"Serial"** device.
   - If not, click **"Add Hardware"** -> **"Serial"**.
   - Ensure the device type is set to **"PTY"**.
6. **Execution**:
   - Click **"Begin Installation"** at the top left.
   - Switch to the serial console via **"View"** -> **"Console"** -> **"Serial 1"**.

## 4. Interaction
1. Once the "Hello, I am saramOS" message appears, click inside the console.
2. Press any number key (0-9).
3. The system will display the CPUID information.
